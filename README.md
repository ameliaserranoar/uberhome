# UberHome — Landing Page

Proyecto académico de investigación de producto.

## Archivos

- `index.html` — Landing page principal
- `feature.html` — Página de detalle de la Red de Confianza (Coming Soon)
- `vercel.json` — Configuración de deploy

## Deploy en Vercel (3 pasos)

1. Sube esta carpeta a un repositorio de GitHub
2. Ve a [vercel.com](https://vercel.com) → "Add New Project"
3. Conecta el repositorio → Deploy automático

## Métricas de tracking

El sitio registra automáticamente en `localStorage`:
- `uberhome_visits` — visitas totales a la landing page
- `uberhome_feature_clicks` — clics en el botón "Nuevo" / Red de Confianza
- `uberhome_feature_page_visits` — visitas a la página del feature
- `uberhome_email_count` — correos registrados en el Coming Soon

Para ver las estadísticas en cualquier momento, abre la consola del navegador y escribe:

```
showStats()
```
